# Furkan Akar

**Full-Stack & Mobile Software Developer** — Istanbul, Türkiye

I build software that connects modern web stacks to real-world operations: React and
Next.js on the front, .NET and Node.js behind, native Android in the field, and Oracle
underneath.

## What I do

- **Day job:** operational software for a nationwide logistics company — native Android
  (Java) apps on Zebra handheld terminals, .NET 8 Web APIs, Oracle PL/SQL integrations,
  and label printing over raw TCP sockets (ZPL/EPL). All of it runs in production, daily.
- **Own products:** a CV-builder SaaS, a RAG chatbot on Qdrant, WhatsApp lead automation,
  and a live e-commerce store I operate myself.
