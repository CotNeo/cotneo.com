## Uluslararası işveren gözüyle olası zayıf noktalar ve dürüst konumlandırma

1. **İngilizce (B1–B2, konuşma gelişiyor).**
   Konumlandırma: "Works comfortably with technical documentation and written communication;
   actively improving spoken fluency." Yazılı iletişimin güçlü olduğunu erken kanıtla
   (temiz cover letter, düzgün PR açıklamaları). Mülakat öncesi konuşma pratiğine yatırım
   en yüksek getirili adım.
2. **Tamamlanmış lisans diploması yok.**
   Konumlandırma: Eğitim bölümünde dürüstçe listele ("ongoing" / "attended through third year"),
   ama CV'nin ağırlığını Professional Experience'a ver. Uluslararası pazarda üretim tecrübesi
   diplomadan daha çok konuşur; savunmaya geçme, gündeme gelirse Full Stack Open + AUZEF ile
   sürekli örgün öğrenmeyi göster.
3. **Tek işveren (aynı organizasyon içinde iki rol).**
   Konumlandırma: İki rolü ayrı girdiler olarak yaz (yaptık) — kariyer ilerlemesi hikâyesine
   dönüşür: operasyondan yazılıma iç geçiş, güçlü bir sinyal.
4. **Ünvanda "Specialist" kelimesinin yazılım dışı algısı.**
   Konumlandırma: Rol adının yanında parantezle işin özünü ver: "Operational Software /
   Mobile Software Specialist (Android, .NET, Oracle)".
5. **Ölçülebilir metrik azlığı.**
   Konumlandırma: Uydurma. Bunun yerine kapsam belirten doğrulanabilir ifadeler kullan:
   "production workflows", "used daily by field staff", "~1,300-device fleet",
   "marketplace order flows (Amazon/Trendyol/N11-style)".

## Ton kuralları (tüm içerikler için)

- Yasaklı: passionate, highly motivated, results-driven, ninja, rockstar, guru,
  cutting-edge, synergy, best-in-class, 10x.
- Her madde şu kalıba yaklaşsın: **ne yaptın + hangi teknolojiyle + hangi problemi çözdün + operasyona etkisi.**
- Metrik yoksa metrik yazma; kapsam yaz.
- Platformlar arasında aynı cümleyi kopyalama: CV kanıt dili, LinkedIn anlatı dili,
  GitHub teknik dil, web sitesi ürün dili kullanır.
