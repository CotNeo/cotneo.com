## About

Most of the software I build gets tested by a courier scanning a barcode, not just by a
test suite.

I'm a full-stack and mobile developer in Istanbul. At a nationwide logistics company I
build the operational software behind daily cargo workflows: native Android (Java) apps
running on Zebra handheld terminals, .NET 8 Web APIs in C#, and the Oracle PL/SQL
procedures they rely on. Order-to-invoice flows, marketplace shipments, label printing
over raw TCP sockets — the kind of software where a bug is visible on a warehouse floor
within minutes.

On the web side I work with React, Next.js, TypeScript and Node.js, and I ship my own
products: a CV-builder SaaS, a retrieval-augmented (RAG) chatbot built on Qdrant, WhatsApp
lead automation, and a live e-commerce store I run in production.

Before moving into development I operated the security technology of the same logistics
network — around 1,300 CCTV and access devices. That's where I learned to treat
monitoring, incident analysis and reliability as part of the job, not an afterthought.

What I'm best at: connecting systems that weren't designed to talk to each other —
a mobile app to a legacy SOAP service, a modern API to a decades-old database schema —
and debugging across all of those layers when something breaks.

Currently learning: AWS, system design and deeper .NET practice.
I'm open to full-stack, backend and mobile roles with international teams, remote or
relocation-supported.
